التركيبInstalling

البرنامج مجاني وغير موقّع من Microsoft أو Apple، فأول مرة بيطلع تحذير. هيك بتتجاوزه:Brusk is free and not signed by Microsoft or Apple, so the first launch shows a warning. Here is how to get past it:

Windows

  1. شغّل Brusk-Setup-Windows.exe.
  2. إذا طلعت شاشة زرقا "Windows protected your PC"، اضغط More info وبعدين Run anyway.
  3. كمّل التنصيب عادي.
  1. Run Brusk-Setup-Windows.exe.
  2. If a blue "Windows protected your PC" screen appears, click More info, then Run anyway.
  3. Finish the installer.

macOS

  1. افتح ملف الـ dmg واسحب Brusk لمجلد Applications.
  2. افتح Terminal والصق: xattr -cr /Applications/Brusk.app
  3. افتح بروسك. (أو: System Settings ← Privacy & Security ← Open Anyway)
  1. Open the dmg and drag Brusk into Applications.
  2. Open Terminal and paste: xattr -cr /Applications/Brusk.app
  3. Open Brusk. (Or: System Settings → Privacy & Security → Open Anyway)

Android

  1. نزّل Brusk-Android.apk من الموبايل وافتحه.
  2. إذا سألك، اسمح بـ تثبيت تطبيقات من هذا المصدر.
  3. بأي تطبيق: مشاركة ← تنزيل ببروسك ← اختار الجودة.
  1. Download Brusk-Android.apk on your phone and open it.
  2. If asked, allow Install from this source.
  3. In any app: Share → Download with Brusk → pick a quality.

Firefox

  1. ركّب الإضافة من صفحة Firefox Add-ons.
  2. اضغط أيقونة بروسك ثم ربط، ووافق بنافذة البرنامج.
  1. Install the add-on from Firefox Add-ons.
  2. Click the Brusk icon, then Connect, and allow it in the app.

Chrome / Edge / Brave

  1. فكّ ضغط Brusk-Chrome-Extension.zip.
  2. افتح chrome://extensions وفعّل Developer mode.
  3. اضغط Load unpacked واختار المجلد، ثم ربط.
  1. Unzip Brusk-Chrome-Extension.zip.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked, pick the folder, then Connect.
